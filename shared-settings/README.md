# 通用总设定集 (Shared Settings & Lore)

本目录用于存放跨作品/全宇宙通用的世界观底层法则、神学法则、魔药守恒定律及历史大事件，为仓库内所有奇幻小说作品提供统一的世界观底座。

---

## 目录索引 (Index)

- **[非凡宇宙底层法则 (`universe_laws.md`)](./universe_laws.md)**：包含非凡三大定律、扮演法理论、锚与人性平衡、神性污染机制等全局法则。

---

## 各作品扩展设定

具体单本小说的专属势力、具体途径序列、角色卡与封印物档案，存放在对应的小说一级目录（如 `book-01-whisper/settings/`）中。
