# 奇幻小说创作仓库

本仓库用于构建原创的悬疑奇幻世界，允许吸收远古神话、英雄群像和侦探推理的气质，但不复制任何现成作品的专有设定、等级结构或剧情机制。

## 工作区

- [`shared-settings/`](./shared-settings/)：跨作品共用的原创宇宙底层规则。
- [`book-01-whisper/`](./book-01-whisper/)：首部作品《裂潮证词》的世界观和后续案件工作区。

## 当前阶段

正式力量体系是“裂印”：少数异常事故在人或物上留下印记，一枚裂印只有一种具体能力，每次使用都要付出固定代价。体系不设等级。

第一阶段只维护世界观总纲和力量体系。人物、封存物、卷册大纲和正文将在规则稳定后重新设计。

## 约束

- 所有能力必须事先写明触发、效果、上限、代价、痕迹和反制手段。
- 悬疑通过互相矛盾但可验证的证据推进，不用作者临时解释解决。
- 新设定发生变化时，同步更新宇宙层、社会层和剧情层文档。
