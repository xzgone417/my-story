# 力量体系：裂印

## 一句话规则

**一次异常事故可能在人或物上留下“裂印”。一枚裂印只有一种能力；每次使用都付出固定代价。**

不设等级、途径或魔药。能力名称可以神秘，实际效果必须能用一句普通话说清楚，例如“听出一句明知故说的假话”或“让碰到的门锁上一分钟”。

每枚裂印的纹路都不同。发动时，作用处会短暂出现同形裂纹，因此印术通常能被事后追查；具体痕迹仍须写进能力记录。

## 谁能使用

- **印者**：在异常事故中幸存、身上留下裂印的人。一个人只能有一枚裂印，觉醒后能力与代价固定，不能换术或升级成另一种能力。
- **印物**：在异常事故中留下裂印的物件。任何人都可能使用，但必须承受它的代价。印物有明确的保管、损坏和隔离方式。
- 同一人同一时刻只能发动一种印术。持有更多印物不会增加自身能力，也不能同时发动多种印术。

裂印从何而来仍是故事的深层谜题；角色使用能力时，不需要先解开这道谜。

## 每种能力都要写清六件事

1. **触发**：使用前必须做什么，例如接触目标、听见声音或看到目标。
2. **效果**：它具体改变什么；只允许一个主要效果。
3. **上限**：距离、对象数量和持续时间分别是多少。不能临场突破。
4. **代价**：每次使用必定发生的身体或记忆损伤，持续多久；即使判断错误或被反制也要付出。
5. **痕迹**：裂印及现场会留下什么可被别人察觉的迹象。
6. **反制**：对手如何避开触发条件、脱离范围或利用能力盲点。

代价未结束前不能再次发动同一枚裂印。训练只能让使用时机和判断更准确，不能增加第二种能力，也不能改写已经定下的上限。

## 两个例子

### 辨谎（印者）

| 项目 | 内容 |
| :--- | :--- |
| 触发 | 选定三步内的一人，专心听其接下来的一句话。 |
| 效果 | 如果对方明知是假话，印者会听到一声细响；不知道真话是什么。对方真心相信的错话不会触发。 |
| 上限 | 一次只判断一句话、一个人；不能判断文字、沉默或隔墙的声音。 |
| 代价 | 无论有没有听到细响，左耳失聪十分钟；恢复前不能再次使用。 |
| 痕迹 | 印者耳后出现短暂的红色裂纹。 |
| 反制 | 说真话但隐去关键部分、使用书面信息，或留在三步之外。 |

### 闭门（印物：铁门牌）

| 项目 | 内容 |
| :--- | :--- |
| 触发 | 用铁门牌碰到一扇有门扇的门。 |
| 效果 | 门自行合拢并保持关闭一分钟；门板仍可被外力破坏。 |
| 上限 | 一次只作用一扇门；不能封住没有门扇的通道。 |
| 代价 | 使用者右手僵硬十分钟；恢复前不能再次使用铁门牌。 |
| 痕迹 | 门牌和门框出现同形的细裂纹，持续一分钟。 |
| 反制 | 事先卸下门扇、破坏门板，或避开门牌的接触。 |

## 创作边界

任何新印术先填完六项，再写入剧情。不能临时增加读心、预知、复活、凭空造物或无条件改写现实等第二效果。案件可以通过现场痕迹、能力盲点和代价反推印者或印物，但不要求读者掌握一套抽象术语才能理解冲突。
