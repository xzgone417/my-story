## 本书基本信息 (Book Information)

- **书名**：《深渊低语》（Whisper of the Abyss）
- **类型**：克苏鲁奇幻 / 维多利亚蒸汽朋克 / 序列魔药 / 悬疑解谜
- **核心基调**：冷峻正剧、悬疑解谜、幕后群像、智斗与规则怪谈
- **一句话简介**：蒸汽与煤烟笼罩的帝都深处，穿越而来的文员揭开了沉睡于绯红之月下的诡秘序列，在古老神明的低语声中建立起隐秘代号聚会。
