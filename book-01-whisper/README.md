# 《裂潮证词》工作区

## 作品定位

以悬疑调查和个人成长为主轴的原创奇幻小说。远古神话、工业时代、英雄群像与侦探推理会在不同阶段承担不同主题；正式能力遵循“一印一术、使用必付代价”的规则。主要舞台是衡川联邦的雾津市。
